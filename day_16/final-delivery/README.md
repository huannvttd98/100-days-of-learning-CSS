## 🎯 使用方法

### GIF版（静的コンテンツ）
- デモ、プレビュー、マーケティング素材として使用
- 固定コンテンツ（テキスト変更不可）
- 実装が簡単

### HTMLコンポーネント版（動的コンテンツ）
- 実際のゲーム実装に使用
- JavaScriptで全てのテキスト・数値を動的に変更可能
- エンジニアが柔軟にカスタマイズ可能

**推奨実装パターン:**
```javascript
// YOU WIN表示例
showYouWin({
  pair: 'BTC/USDT',
  price: 87776.94,
  change: 0.14,
  amount: 10.00,
  theme: 'blue'
});

// スクイーズ表示例
showSqueeze({
  pair: 'ETH/USDT',
  theme: 'cyan'
});
```

詳細な実装方法は各コンポーネントのREADME.mdを参照してください。

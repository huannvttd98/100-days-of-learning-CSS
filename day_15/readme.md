# 🏆 YOU WIN UI – Canvas Coin Effect

Giao diện thông báo chiến thắng (**YOU WIN**) với **hiệu ứng coin rơi mượt bằng HTML5 Canvas**.
Thiết kế theo phong cách **Game / Crypto / Trading**, tối ưu cho **Web, PWA, Mobile WebView**.

---

## 📌 Tổng quan
- UI thông báo chiến thắng
- Coin rơi & xoay bằng Canvas (hiệu năng cao)
- Không dùng framework
- Dễ tích hợp vào Vue / React / Quasar

---

## 🎯 Mục tiêu dự án
- Tạo hiệu ứng chiến thắng trực quan
- Đảm bảo mượt khi coin nhiều
- Code dễ đọc, dễ mở rộng
- Phù hợp cho production

---

## 🧩 Tính năng chính
- YOU WIN text (glow)
- Hiển thị lợi nhuận (+$)
- Coin rơi / xoay bằng Canvas
- Không ảnh hưởng DOM
- Chạy mượt 60fps

---

## 🧰 Công nghệ sử dụng
| Công nghệ | Mô tả |
|--------|------|
| HTML5 | Cấu trúc UI |
| CSS3 | Layout, Glow, Animation |
| Canvas API | Vẽ coin |
| JavaScript | Logic animation |
| requestAnimationFrame | Loop mượt |
